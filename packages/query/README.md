# @oofp/query

Librería de query builders funcionales para TypeScript con tipos type-safe.

## Instalación

```bash
pnpm install @oofp/query
```

## Desarrollo

```bash
# Instalar dependencias
pnpm install

# Modo desarrollo
pnpm dev

# Ejecutar tests
pnpm test

# Ejecutar tests en modo watch
pnpm test:watch

# Build
pnpm build

# Coverage
pnpm coverage
```
